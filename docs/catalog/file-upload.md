| ID     | Behavior                 | Aturan Standar                                                                                                                                                                    |
| ------ | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| UPL-01 | Informasi ketentuan      | Tampilkan format yang diperbolehkan, ukuran maksimum per file, dan jumlah maksimum file sebelum pengguna memilih file.                                                            |
| UPL-02 | Pemilihan file           | Pengguna dapat memilih file melalui tombol unggah. Jika drag and drop tersedia, aturan validasinya sama dengan pemilihan melalui tombol.                                          |
| UPL-03 | Membatalkan pemilihan    | Membatalkan dialog pemilihan file tidak mengubah file yang sudah dipilih atau tersimpan.                                                                                          |
| UPL-04 | Format file              | File harus sesuai dengan format yang diperbolehkan. Server memeriksa jenis dan isi file; pemeriksaan tidak hanya berdasarkan ekstensi atau informasi dari browser.                |
| UPL-05 | Ukuran file              | File yang melebihi ukuran maksimum ditolak dengan pesan yang menjelaskan batasnya. File yang ukurannya tepat pada batas maksimum tetap diterima.                                  |
| UPL-06 | File kosong              | File berukuran 0 byte ditolak dengan pesan bahwa file kosong tidak dapat diunggah.                                                                                                |
| UPL-07 | Jumlah file              | Jumlah file tidak boleh melebihi batas yang ditentukan. Pada unggah jamak, batas menghitung file tersimpan yang dipertahankan dan file baru yang dipilih.                         |
| UPL-08 | Nama file                | Nama asli ditampilkan sebagai teks. File dengan nama sama tidak boleh menimpa file tersimpan secara otomatis.                                                                     |
| UPL-09 | Informasi file terpilih  | Setelah dipilih, tampilkan nama, ukuran, dan status setiap file agar pengguna mengetahui file yang akan diunggah.                                                                 |
| UPL-10 | Preview file             | Jika format mendukung preview, tampilkan pratinjau. Jika preview tidak tersedia, informasi file tetap ditampilkan dan file yang valid tetap dapat diunggah.                       |
| UPL-11 | Pemicu unggah            | Unggah dimulai setelah file lolos validasi dan pengguna menjalankan aksi Upload atau Submit. Pemilihan file tidak otomatis berarti file sudah tersimpan.                          |
| UPL-12 | Progres unggah           | Selama unggah berlangsung, tampilkan status proses per file. Persentase ditampilkan jika progres dapat diukur.                                                                    |
| UPL-13 | Unggah berhasil          | File ditandai berhasil setelah server mengonfirmasi penerimaannya. Jika masih membutuhkan pemrosesan atau penyimpanan form, tampilkan status tersebut secara terpisah.            |
| UPL-14 | Unggah gagal             | Tampilkan pesan gagal pada file terkait. File lain yang berhasil tidak ditandai gagal atau diunggah ulang tanpa kebutuhan.                                                        |
| UPL-15 | Mencoba kembali          | Pengguna dapat mengulang unggah file yang gagal. Percobaan ulang tidak boleh menghasilkan lampiran ganda untuk unggahan yang sama.                                                |
| UPL-16 | Menghapus pilihan        | Pengguna dapat menghapus file yang belum tersimpan dari daftar pilihan. File tersebut tidak disertakan dalam pengiriman berikutnya.                                               |
| UPL-17 | Membatalkan unggah       | Jika tersedia, aksi Cancel menghentikan unggah yang sedang berjalan. File yang dibatalkan tidak ditautkan sebagai lampiran; file sementara dibersihkan sesuai kebijakan aplikasi. |
| UPL-18 | Mengganti file           | File lama tetap tersedia sampai file pengganti berhasil diunggah dan perubahan berhasil disimpan. Jika penggantian gagal atau dibatalkan, file lama tetap dipertahankan.          |
| UPL-19 | Menghapus file tersimpan | Penghapusan memerlukan konfirmasi. Pada form edit, file baru benar-benar dilepas setelah perubahan berhasil disimpan.                                                             |
| UPL-20 | Kegagalan sebagian       | Pada unggah jamak, tampilkan hasil per file. File tidak valid tidak ikut diunggah; file valid tetap dapat diproses jika kegagalan sebagian diperbolehkan.                         |
| UPL-21 | Field lampiran wajib     | Form hanya dapat disimpan jika terdapat file yang memenuhi ketentuan dan unggahnya berhasil. File gagal atau dibatalkan tidak dihitung sebagai lampiran.                          |
| UPL-22 | Hak akses file           | Server memeriksa hak pengguna untuk mengunggah, melihat, mengganti, dan menghapus file, termasuk melalui akses URL atau API langsung.                                             |
| UPL-23 | Pemeriksaan keamanan     | File yang terdeteksi berbahaya ditolak. Jika pemeriksaan belum selesai, tampilkan status pemeriksaan dan jangan sediakan file untuk digunakan atau diunduh.                       |
| UPL-24 | Meninggalkan form        | Jika pengguna meninggalkan form tanpa menyimpan, file yang baru diunggah tidak dianggap sebagai lampiran permanen. File sementara dibersihkan sesuai kebijakan aplikasi.          |
