| ID     | Behavior                  | Aturan Standar                                                                                                                                                                    |
| ------ | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RSP-01 | Penyesuaian layout        | Layout menyesuaikan lebar viewport tanpa konten bertumpuk, terpotong, atau kehilangan fungsi.                                                                                     |
| RSP-02 | Breakpoint                | Perubahan susunan komponen menggunakan breakpoint yang disepakati tim. Perilaku pada batas breakpoint harus konsisten.                                                            |
| RSP-03 | Lebar konten              | Konten mengikuti ruang yang tersedia dengan padding dan batas lebar maksimum yang ditentukan pada panduan desain.                                                                 |
| RSP-04 | Scroll horizontal halaman | Halaman tidak membutuhkan scroll horizontal untuk membaca konten utama. Komponen yang memerlukan ruang lebar, seperti tabel, menggunakan area scroll tersendiri.                  |
| RSP-05 | Urutan konten             | Perubahan dari beberapa kolom menjadi satu kolom mempertahankan urutan baca dan prioritas informasi yang logis.                                                                   |
| RSP-06 | Navigasi utama            | Navigasi dapat berubah menjadi drawer atau menu ringkas saat ruang terbatas. Seluruh tujuan yang diizinkan tetap dapat dijangkau.                                                 |
| RSP-07 | Header dan toolbar        | Judul, pencarian, dan tombol aksi dapat berpindah baris tanpa saling menutupi. Aksi utama tetap mudah ditemukan.                                                                  |
| RSP-08 | Form                      | Form beberapa kolom berubah menjadi satu kolom saat ruang tidak cukup. Label, petunjuk, dan pesan validasi tetap terlihat dekat field terkait.                                    |
| RSP-09 | Kelompok tombol           | Tombol dapat berpindah baris atau disusun vertikal. Urutan dan penekanan aksi utama serta sekunder tetap konsisten.                                                               |
| RSP-10 | Pencarian dan filter      | Kontrol dapat disusun vertikal atau dipindahkan ke panel filter. Nilai aktif dan cara mengubah atau meresetnya tetap tersedia.                                                    |
| RSP-11 | Tabel data                | Tabel menggunakan scroll horizontal, tampilan kartu, atau pengaturan kolom yang telah ditentukan. Informasi dan aksi penting tetap dapat diakses.                                 |
| RSP-12 | Kolom yang disembunyikan  | Kolom boleh disembunyikan pada layar kecil yang telah ditentukan. Informasi yang masih dibutuhkan tersedia melalui detail atau mekanisme lain.                                    |
| RSP-13 | Pagination                | Kontrol pagination dapat diringkas tanpa menghilangkan cara berpindah halaman dan mengetahui halaman aktif.                                                                       |
| RSP-14 | Dialog                    | Dialog menyesuaikan viewport. Jika konten panjang, area kontennya dapat di-scroll dan tombol aksi tetap dapat dijangkau.                                                          |
| RSP-15 | Dropdown dan popover      | Panel menyesuaikan posisi agar tidak keluar dari viewport. Opsi panjang dapat di-scroll dan tidak terpotong tanpa cara mengaksesnya.                                              |
| RSP-16 | Teks panjang              | Nama, judul, URL, dan nilai panjang tidak merusak layout. Jika dipotong dengan ellipsis, nilai lengkap tersedia melalui cara yang dapat digunakan pada layar sentuh dan keyboard. |
| RSP-17 | Gambar dan media          | Media menyesuaikan ukuran kontainer dengan mempertahankan rasio. Pemotongan gambar tidak menghilangkan informasi penting.                                                         |
| RSP-18 | Grafik                    | Grafik menyesuaikan ruang tersedia. Label, legenda, dan nilai tetap dapat dibaca atau tersedia melalui tampilan alternatif.                                                       |
| RSP-19 | Elemen sticky dan fixed   | Header, footer, dan tombol mengambang tidak menutupi konten, pesan validasi, atau elemen yang sedang menerima fokus.                                                              |
| RSP-20 | Keyboard virtual          | Saat keyboard perangkat terbuka, field aktif tetap dapat dilihat dan tombol yang diperlukan tetap dapat dijangkau melalui scroll.                                                 |
| RSP-21 | Perubahan orientasi       | Pergantian portrait dan landscape menyesuaikan layout tanpa menghapus input, pilihan, atau status proses yang sedang berjalan.                                                    |
| RSP-22 | Perubahan ukuran jendela  | Resize tidak mereset pencarian, filter, pagination, tab aktif, atau input form. Komponen yang berubah bentuk tetap mempertahankan keadaan yang relevan.                           |
| RSP-23 | Interaksi layar sentuh    | Aksi tidak hanya bergantung pada hover. Tombol dan kontrol memiliki area sentuh serta jarak sesuai panduan aksesibilitas tim.                                                     |
| RSP-24 | Feedback                  | Loading, empty state, pesan kesalahan, dan toast menyesuaikan ruang tanpa menutupi aksi penting atau keluar dari viewport.                                                        |
| RSP-25 | Ruang vertikal terbatas   | Pada viewport pendek, seluruh konten dan aksi tetap dapat dijangkau. Tinggi tetap pada komponen tidak boleh menyebabkan konten terkunci atau terpotong.                           |
