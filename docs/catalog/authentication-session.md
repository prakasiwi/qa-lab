| ID     | Behavior                      | Aturan Standar                                                                                                                                                                                                    |
| ------ | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AUT-01 | Akses halaman terlindungi     | Pengguna yang belum memiliki sesi valid diarahkan ke halaman login saat membuka halaman yang membutuhkan autentikasi. Permintaan API tanpa autentikasi valid ditolak tanpa mengembalikan data terlindungi.        |
| AUT-02 | Metode login                  | Pengguna masuk menggunakan metode yang ditentukan pada FSD, misalnya email dan password atau SSO.                                                                                                                 |
| AUT-03 | Kerahasiaan password          | Input password disamarkan secara default. Jika tersedia, tombol tampilkan/sembunyikan password tidak mengubah nilainya.                                                                                           |
| AUT-04 | Login berhasil                | Sesi dibuat setelah seluruh tahap autentikasi yang diwajibkan selesai. Pengguna kemudian diarahkan ke halaman tujuan yang diperbolehkan.                                                                          |
| AUT-05 | Login gagal                   | Jika identitas atau password salah, tampilkan pesan umum seperti “Email atau password tidak sesuai” tanpa mengungkapkan apakah akun terdaftar.                                                                  |
| AUT-06 | Akun tidak memenuhi syarat    | Akun nonaktif, diblokir, atau belum memenuhi persyaratan aktivasi tidak memperoleh sesi aplikasi. Informasi dan langkah lanjut yang ditampilkan mengikuti kebijakan pada FSD.                                     |
| AUT-07 | Pembatasan percobaan          | Percobaan login dibatasi oleh server. Setelah batas tercapai, percobaan berikutnya ditunda atau ditolak sementara sesuai kebijakan aplikasi.                                                                      |
| AUT-08 | Gangguan layanan login        | Jika layanan autentikasi bermasalah, tampilkan pesan gangguan dan opsi mencoba kembali. Gangguan tidak dinyatakan sebagai kesalahan password.                                                                     |
| AUT-09 | Tujuan setelah login          | Jika pengguna sebelumnya membuka halaman terlindungi, kembalikan ke tujuan tersebut setelah login jika masih diizinkan. Tujuan pengalihan harus diperiksa agar tidak mengarah ke alamat yang tidak diperbolehkan. |
| AUT-10 | Autentikasi bertahap          | Jika MFA diwajibkan, keberhasilan password hanya membuka tahap verifikasi berikutnya. Pengguna belum dapat mengakses data terlindungi sebelum seluruh tahap selesai.                                              |
| AUT-11 | Validasi kode verifikasi      | Kode harus sesuai dengan pengguna, tujuan, dan proses autentikasi yang sedang berjalan. Kode salah, kedaluwarsa, atau sudah digunakan ditolak.                                                                    |
| AUT-12 | Pengiriman ulang kode         | Pengiriman ulang mengikuti jeda waktu dan batas permintaan. Masa berlaku serta perlakuan terhadap kode sebelumnya ditentukan.                                                                                     |
| AUT-13 | Lupa password                 | Permintaan reset menampilkan respons umum tanpa mengungkapkan apakah akun terdaftar. Instruksi dikirim melalui kanal pemulihan yang sudah terverifikasi jika akun memenuhi syarat.                                |
| AUT-14 | Tautan reset password         | Tautan reset memiliki masa berlaku dan hanya dapat digunakan untuk satu reset yang berhasil. Membuka tautan saja tidak mengubah password atau membuat sesi login.                                                 |
| AUT-15 | Reset password berhasil       | Setelah password berhasil diubah melalui reset, sesi dan proses login sementara sebelumnya dicabut. Pengguna diminta login menggunakan password baru.                                                             |
| AUT-16 | Penggunaan ulang tautan reset | Tautan yang kedaluwarsa, sudah digunakan, atau telah dicabut ditolak dengan pesan yang mengarahkan pengguna untuk mengajukan reset baru.                                                                          |
