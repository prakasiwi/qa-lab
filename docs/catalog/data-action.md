| ID     | Behavior                      | Aturan Standar                                                                                                                                                                                                      |
| ------ | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ACT-01 | Ketersediaan aksi             | Aksi yang ditampilkan mengikuti hak akses pengguna dan kondisi data. Aksi yang tidak diizinkan karena hak akses disembunyikan; aksi yang belum tersedia karena kondisi data dinonaktifkan dengan penjelasan alasan. |
| ACT-02 | Pemeriksaan di server         | Server memeriksa hak akses dan kondisi data setiap kali aksi dijalankan, termasuk melalui API langsung.                                                                                                             |
| ACT-03 | Tambah data                   | Aksi Add membuka form baru dengan nilai awal yang telah ditentukan. Input dari form sebelumnya tidak terbawa, kecuali ditentukan sebagai nilai awal.                                                                |
| ACT-04 | Lihat detail                  | Aksi View membuka detail data yang dipilih. Informasi yang ditampilkan mengikuti hak akses pengguna.                                                                                                                |
| ACT-05 | Edit data                     | Aksi Edit membuka form berisi nilai terbaru dari data yang dipilih. Field yang dapat diubah mengikuti hak akses dan kondisi data.                                                                                   |
| ACT-06 | Identitas data                | Setiap aksi menggunakan identitas unik data. Kesamaan nama atau perubahan urutan daftar tidak boleh menyebabkan aksi dijalankan pada data lain.                                                                     |
| ACT-07 | Hapus data                    | Aksi Delete meminta konfirmasi sebelum dijalankan. Konfirmasi menampilkan identitas data dan dampak penghapusan yang relevan.                                                                                       |
| ACT-08 | Pembatalan hapus              | Memilih Cancel pada konfirmasi menutup dialog tanpa menghapus atau mengubah data.                                                                                                                                   |
| ACT-09 | Hasil penghapusan             | Setelah berhasil dihapus, data tidak muncul pada daftar aktif dan tidak dapat diproses melalui aksi biasa. Penghapusan permanen atau penyimpanan sebagai arsip atau soft delete yang telah ditentukan.              |
| ACT-10 | Data memiliki relasi          | Jika data masih digunakan oleh data lain, penghapusan ditolak dengan penjelasan relasinya. Penghapusan beserta data terkait hanya diperbolehkan jika ditetapkan secara eksplisit.                                   |
| ACT-11 | Duplikasi data                | Aksi Duplicate membuka form baru dengan salinan field yang telah ditentukan. Identitas unik, riwayat aktivitas, dan status persetujuan tidak disalin.                                                               |
| ACT-12 | Nilai unik pada duplikasi     | Field yang harus unik dikosongkan atau diberi nilai awal baru yang telah ditentukan. Data hasil duplikasi tetap diperiksa sebelum disimpan.                                                                         |
| ACT-13 | Aktivasi dan nonaktivasi      | Perubahan status aktif tidak menghapus data atau riwayatnya. Dampak terhadap penggunaan data pada transaksi baru yang telah ditentukan.                                                                             |
| ACT-14 | Pemilihan data massal         | Pengguna dapat memilih satu atau beberapa data yang memenuhi syarat untuk aksi massal. Tampilkan jumlah data yang dipilih.                                                                                          |
| ACT-15 | Pilih semua                   | Checkbox pada header memilih seluruh data yang dapat dipilih pada halaman aktif. Pemilihan seluruh hasil pencarian harus disediakan sebagai aksi terpisah dengan cakupan yang jelas.                                |
| ACT-16 | Perubahan kondisi daftar      | Pergantian halaman, pencarian, filter, atau sortir menghapus pilihan data massal agar tidak ada pilihan tersembunyi yang ikut diproses.                                                                             |
| ACT-17 | Ketersediaan aksi massal      | Tombol aksi massal hanya aktif jika ada data yang dipilih dan seluruh pilihan memenuhi syarat aksi. Jika tidak, tampilkan alasan.                                                                                   |
| ACT-18 | Konfirmasi aksi massal        | Sebelum aksi massal yang menghapus atau mengubah data dijalankan, tampilkan jenis aksi dan jumlah data yang akan diproses.                                                                                          |
| ACT-19 | Pemeriksaan ulang aksi massal | Server memeriksa setiap data yang dipilih saat aksi dijalankan. Data yang sudah berubah atau tidak lagi diizinkan tidak boleh diproses tanpa pemeriksaan.                                                           |
| ACT-20 | Hasil aksi massal             | Tampilkan jumlah data berhasil dan gagal diproses. Jika kegagalan sebagian diperbolehkan, sertakan identitas data yang gagal beserta alasannya.                                                                     |
| ACT-21 | Data tidak tersedia           | Jika data sudah dihapus atau tidak lagi dapat diakses, tampilkan pesan yang sesuai dan perbarui daftar. Detail yang tidak boleh diakses tidak ditampilkan.                                                          |
| ACT-22 | Kondisi data berubah          | Jika status data berubah setelah halaman dibuka, gunakan kondisi terbaru untuk menentukan apakah aksi masih diperbolehkan. Jika ditolak, jelaskan alasannya dan perbarui tampilan.                                  |
| ACT-23 | Pembaruan setelah aksi        | Setelah aksi berhasil, perbarui daftar atau detail terkait. Pertahankan pencarian, filter, dan sortir aktif; penyesuaian halaman mengikuti `pagination.md`.                                                       |
| ACT-24 | Data keluar dari hasil daftar | Jika hasil edit atau perubahan status membuat data tidak lagi memenuhi pencarian atau filter aktif, data dikeluarkan dari daftar dan tetap diberikan pesan keberhasilan.                                            |
