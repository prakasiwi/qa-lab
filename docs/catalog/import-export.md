| ID     | Behavior                     | Aturan Standar                                                                                                                                                                                            |
| ------ | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IMP-01 | Hak akses impor              | Server memeriksa hak pengguna untuk mengimpor data, termasuk hak menambah atau memperbarui data pada cakupan tujuan.                                                                                      |
| IMP-02 | Template impor               | Sediakan template yang dapat diunduh, berisi nama kolom, petunjuk field wajib, dan contoh pengisian yang dibedakan dari data sebenarnya.                                                                  |
| IMP-03 | Format file                  | File harus menggunakan format yang telah ditentukan. File rusak, dilindungi password, atau tidak dapat dibaca ditolak dengan alasan yang jelas.                                                           |
| IMP-04 | Struktur file                | Periksa sheet, header, dan kolom wajib sebelum memproses baris. Jika struktur tidak sesuai, hentikan impor dan jelaskan bagian yang perlu diperbaiki.                                                     |
| IMP-05 | Pemetaan kolom               | Kolom file dipetakan berdasarkan nama header, bukan hanya posisi. Header yang hilang, berulang, atau tidak dikenal ditangani sesuai ketentuan yang telah disepakati.                                      |
| IMP-06 | File tanpa data              | File yang hanya berisi header atau baris kosong ditolak dengan pesan bahwa tidak ada data untuk diimpor.                                                                                                  |
| IMP-07 | Batas jumlah data            | Jumlah baris tidak boleh melebihi batas. Jika melebihi batas, file ditolak sebelum penyimpanan dan batas yang berlaku ditampilkan.                                                                        |
| IMP-08 | Baris kosong                 | Baris yang seluruh kolomnya kosong diabaikan. Baris yang hanya terisi sebagian tetap diperiksa berdasarkan aturan field wajib.                                                                            |
| IMP-09 | Interpretasi nilai           | Format tanggal, pemisah desimal, dan kode mengikuti ketentuan yang telah disepakati. Nilai ambigu tidak ditebak; kode seperti `00123` tetap dipertahankan sebagai teks.                                 |
| IMP-10 | Validasi per baris           | Setiap baris diperiksa terhadap field wajib, format, batas nilai, dan hubungan antarfield sebelum disimpan.                                                                                               |
| IMP-11 | Validasi referensi           | Nilai yang merujuk data lain harus cocok dengan referensi yang tersedia dan boleh digunakan. Contoh: Kode Kategori harus terdaftar dan aktif.                                                             |
| IMP-12 | Duplikat dalam file          | Data duplikat diperiksa menggunakan field kunci yang telah disepakati. Baris yang berulang ditandai; tidak boleh saling menimpa secara diam-diam.                                                         |
| IMP-13 | Data sudah terdaftar         | Perlakuan terhadap data yang sudah ada harus ditentukan: ditolak, dilewati, atau diperbarui. Pembaruan hanya dilakukan jika mode tersebut didukung dan diizinkan.                                         |
| IMP-14 | Ringkasan sebelum proses     | Sebelum menyimpan, tampilkan jumlah baris dibaca, valid, tidak valid, dan duplikat. Pengguna dapat melanjutkan atau membatalkan sesuai kebijakan kegagalan yang telah disepakati.                         |
| IMP-15 | Kebijakan kegagalan          | Tentukan apakah impor harus berhasil seluruhnya atau boleh sebagian. Untuk mode seluruhnya, satu baris tidak valid membatalkan seluruh penyimpanan. Untuk mode sebagian, hanya baris valid yang disimpan. |
| IMP-16 | Pemeriksaan saat penyimpanan | Server memeriksa kembali aturan yang dapat berubah, seperti keunikan dan ketersediaan referensi, saat penyimpanan dijalankan.                                                                             |
| IMP-17 | Status proses                | Tampilkan status menunggu, diproses, selesai, atau gagal. Permintaan yang baru diterima tidak langsung dinyatakan sebagai impor selesai.                                                                  |
| IMP-18 | Pencegahan proses ganda      | Klik berulang atau percobaan ulang permintaan yang sama tidak boleh menjalankan pekerjaan impor atau menghasilkan data ganda.                                                                             |
| IMP-19 | Hasil impor                  | Setelah selesai, tampilkan jumlah baris berhasil, gagal, dan dilewati. Jumlah tersebut harus sesuai dengan total baris data yang diproses.                                                                |
| IMP-20 | Laporan kesalahan            | Sediakan rincian nomor baris asal, field, dan alasan kegagalan agar pengguna dapat memperbaiki data. Laporan hanya memuat data yang boleh diakses pengguna.                                               |
| IMP-21 | Gangguan dan percobaan ulang | Jika koneksi terputus, periksa status pekerjaan sebelum mengulang impor. Untuk hasil sebagian, percobaan ulang harus mengikuti aturan duplikat dan tidak menggandakan data yang sudah tersimpan.          |
