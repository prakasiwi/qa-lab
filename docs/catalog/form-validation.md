| ID     | Behavior                    | Aturan Standar                                                                                                                                                                                                         |
| ------ | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| VAL-01 | Field wajib                 | Field wajib diberi penanda yang konsisten. Form tidak dapat dikirim jika field wajib belum diisi.                                                                                                                      |
| VAL-02 | Field opsional              | Field opsional boleh dikosongkan. Jika diisi, nilainya tetap harus memenuhi aturan validasi.                                                                                                                           |
| VAL-03 | Input hanya spasi           | Input teks yang hanya berisi spasi dianggap kosong. Pada field wajib, tampilkan pesan validasi.                                                                                                                        |
| VAL-04 | Spasi awal dan akhir        | Spasi di awal dan akhir input teks dihapus sebelum validasi dan penyimpanan, kecuali pada field yang harus mempertahankan nilai persis seperti password.                                                               |
| VAL-05 | Format input                | Nilai harus sesuai format field yang telah ditentukan, misalnya email, nomor telepon, atau kode tertentu.                                                                                                              |
| VAL-06 | Panjang karakter            | Input harus memenuhi panjang minimum dan maksimum yang telah ditentukan. Pesan validasi menjelaskan batas yang berlaku.                                                                                                |
| VAL-07 | Karakter yang diperbolehkan | Pembatasan karakter hanya diterapkan pada field yang memiliki aturan khusus. Karakter seperti apostrof dan tanda hubung tetap diperbolehkan pada teks bebas.                                                           |
| VAL-08 | Input angka                 | Field angka hanya menerima nilai numerik sesuai ketentuan field. Nilai `0` dianggap sebagai nilai yang terisi, bukan input kosong.                                                                                   |
| VAL-09 | Batas nilai angka           | Angka harus memenuhi nilai minimum dan maksimum yang telah ditentukan, termasuk ketentuan boleh atau tidaknya nilai negatif.                                                                                           |
| VAL-10 | Angka desimal               | Jumlah digit desimal dan pemisah desimal mengikuti ketentuan field. Nilai yang melebihi presisi ditolak dengan pesan validasi.                                                                                         |
| VAL-11 | Tanggal valid               | Tanggal harus benar secara kalender. Nilai seperti 31 Februari tidak dapat diterima.                                                                                                                                   |
| VAL-12 | Batas tanggal               | Tanggal harus memenuhi rentang yang telah ditentukan, misalnya tidak boleh melewati hari ini atau tidak boleh sebelum tanggal tertentu.                                                                                |
| VAL-13 | Hubungan antarfield         | Field yang saling berkaitan harus memenuhi aturan hubungan. Contoh: Tanggal Selesai tidak boleh lebih awal dari Tanggal Mulai.                                                                                         |
| VAL-14 | Field wajib bersyarat       | Field menjadi wajib ketika kondisi tertentu terpenuhi. Contoh: Alasan Penolakan wajib diisi jika Status = Rejected.                                                                                                    |
| VAL-15 | Field tidak berlaku         | Field yang tidak berlaku berdasarkan kondisi form tidak menghalangi pengiriman. Nilainya tidak diproses sebagai input aktif.                                                                                           |
| VAL-16 | Pilihan yang valid          | Nilai dropdown, radio, atau pilihan lain harus berasal dari opsi yang masih tersedia dan boleh digunakan pengguna.                                                                                                     |
| VAL-17 | Keunikan data               | Field unik tidak boleh menggunakan nilai yang sudah terdaftar dalam cakupan keunikan yang telah ditentukan. Saat edit, nilai milik data itu sendiri tidak dianggap duplikat.                                           |
| VAL-18 | Konfirmasi nilai            | Field konfirmasi harus sesuai dengan field sumber. Contoh: Konfirmasi Password harus sama dengan Password.                                                                                                             |
| VAL-19 | Waktu validasi              | Validasi field dijalankan setelah pengguna meninggalkan field yang telah diubah. Saat Submit, seluruh field yang berlaku diperiksa kembali.                                                                            |
| VAL-20 | Pesan kesalahan             | Pesan ditampilkan di dekat field terkait, menjelaskan masalah dan cara memperbaikinya. Nilai input pengguna tetap dipertahankan.                                                                                       |
| VAL-21 | Beberapa kesalahan          | Jika terdapat kesalahan pada beberapa field, tampilkan pesan pada seluruh field terkait. Jika satu field memiliki beberapa kesalahan, tampilkan pesan paling mendasar terlebih dahulu, mulai dari kewajiban pengisian. |
| VAL-22 | Perbaikan input             | Field yang memiliki kesalahan diperiksa kembali saat nilainya diubah. Pesan dihapus setelah nilai memenuhi aturan.                                                                                                     |
| VAL-23 | Fokus saat submit gagal     | Jika Submit gagal karena validasi, arahkan fokus ke field pertama yang bermasalah dan pastikan field tersebut terlihat.                                                                                                |
| VAL-24 | Validasi di server          | Server memeriksa kembali seluruh aturan yang berlaku, termasuk ketika permintaan dikirim langsung melalui API tanpa melalui form.                                                                                      |
| VAL-25 | Kesalahan dari server       | Kesalahan validasi dari server ditampilkan pada field terkait. Jika tidak terkait dengan satu field, tampilkan pada area pesan form.                                                                                   |
| VAL-26 | Pemeriksaan belum selesai   | Jika validasi memerlukan pemeriksaan server, tampilkan status pemeriksaan. Form tidak dikirim sebelum pemeriksaan yang wajib selesai.                                                                                  |
| VAL-27 | Pemeriksaan gagal           | Jika pemeriksaan server gagal karena gangguan koneksi atau layanan, tampilkan pesan dan opsi mencoba kembali. Nilai tidak dinyatakan valid atau tidak valid tanpa hasil pemeriksaan.                                   |
| VAL-28 | Pemeriksaan berurutan       | Jika nilai berubah ketika pemeriksaan server masih berjalan, hasil pemeriksaan nilai lama tidak boleh menggantikan hasil untuk nilai terbaru.                                                                          |
