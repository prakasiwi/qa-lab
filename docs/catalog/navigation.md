| ID     | Behavior                                 | Aturan Standar                                                                                                                                                                                  |
| ------ | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| NAV-01 | Tujuan navigasi                          | Setiap menu, tautan, dan tombol navigasi membuka tujuan yang sesuai dengan label dan konteksnya.                                                                                                |
| NAV-02 | Halaman awal                             | Saat membuka alamat utama aplikasi, pengguna diarahkan ke halaman awal sesuai status login dan hak aksesnya. Halaman tujuan yang telah ditentukan.                                              |
| NAV-03 | Menu aktif                               | Menu yang sesuai dengan halaman saat ini memiliki indikator aktif. Halaman detail atau edit tetap menandai menu modul terkait sebagai aktif.                                                    |
| NAV-04 | Submenu                                  | Menu yang memiliki submenu dapat dibuka dan ditutup. Saat halaman anak dibuka, kelompok menu terkait terbuka agar lokasi halaman terlihat.                                                      |
| NAV-05 | Breadcrumb                               | Breadcrumb menunjukkan hierarki halaman. Bagian sebelumnya dapat diklik, sedangkan halaman saat ini ditampilkan sebagai teks yang tidak dapat diklik.                                           |
| NAV-06 | Akses URL langsung                       | URL halaman dapat dibuka langsung selama pengguna memenuhi persyaratan login, hak akses, dan konteks yang diperlukan.                                                                           |
| NAV-07 | Memuat ulang halaman                     | Refresh mempertahankan halaman dan identitas data pada URL. Kondisi pencarian, filter, sortir, dan pagination mengikuti katalog masing-masing.                                                  |
| NAV-08 | Tombol kembali aplikasi                  | Tombol Back atau Kembali pada halaman menuju halaman induk yang ditentukan pada FSD, sehingga tetap berfungsi ketika halaman dibuka melalui URL langsung.                                       |
| NAV-09 | Back dan Forward browser                 | Tombol Back dan Forward browser mengikuti riwayat navigasi serta menampilkan halaman sesuai URL dan hak akses terbaru.                                                                          |
| NAV-10 | Kembali dari detail                      | Saat kembali dari detail ke daftar melalui navigasi aplikasi, pulihkan pencarian, filter, sortir, dan pagination sebelumnya. Jika tidak ada kondisi sebelumnya, gunakan kondisi default daftar. |
| NAV-11 | Perubahan belum disimpan                 | Perpindahan yang akan membuang perubahan form meminta konfirmasi. Memilih Tetap di Halaman mempertahankan input; memilih Buang Perubahan melanjutkan navigasi.                                  |
| NAV-12 | Refresh atau tutup tab saat form berubah | Jika ada perubahan yang belum disimpan, gunakan peringatan bawaan browser jika didukung. Pemulihan input setelah halaman ditutup atau dimuat ulang.                                             |
| NAV-13 | Navigasi saat proses berjalan            | Meninggalkan halaman tidak dianggap otomatis membatalkan proses di server. Saat halaman dibuka kembali, tampilkan status proses atau data terbaru.                                              |
| NAV-14 | URL tidak dikenal                        | URL yang tidak terdaftar menampilkan halaman “Halaman tidak ditemukan” dengan tautan ke tujuan yang dapat diakses.                                                                            |
| NAV-15 | Data tujuan tidak tersedia               | Jika data sudah dihapus atau tidak dapat ditemukan, tampilkan pesan yang sesuai dan sediakan navigasi kembali ke daftar terkait.                                                                |
| NAV-16 | Akses tujuan ditolak                     | Jika pengguna tidak berhak membuka tujuan, ikuti respons penolakan pada `authorization.md`. Konten terlindungi tidak ditampilkan sebelum pemeriksaan selesai.                                 |
| NAV-17 | Perubahan konteks                        | Saat organisasi, project, atau workspace berubah, periksa kembali kesesuaian halaman aktif. Jika halaman tidak berlaku pada konteks baru, arahkan ke halaman awal konteks tersebut.             |
| NAV-18 | Membuka tab baru                         | Tautan internal menuju halaman dapat dibuka pada tab baru melalui perilaku standar browser. Tab baru tetap menjalankan pemeriksaan sesi, hak akses, dan konteks.                                |
| NAV-19 | Tautan eksternal                         | Tujuan di luar aplikasi ditandai dengan jelas. Jika dibuka pada tab baru, pengguna mendapat indikator yang konsisten.                                                                           |
| NAV-20 | Tab dalam halaman                        | Pergantian tab menampilkan konten sesuai label dan memperbarui indikator tab aktif. Tab default dan penyimpanan tab aktif pada URL yang telah ditentukan.                                       |
| NAV-21 | Proses memuat halaman                    | Selama tujuan dimuat, tampilkan indikator loading. Halaman belum dinyatakan tidak ditemukan hanya karena data masih dimuat.                                                                     |
| NAV-22 | Gagal memuat tujuan                      | Tampilkan pesan gangguan dan opsi mencoba kembali. Sediakan navigasi ke halaman lain yang masih dapat diakses.                                                                                  |
| NAV-23 | Navigasi berurutan                       | Jika pengguna memilih beberapa tujuan secara berdekatan, halaman akhir mengikuti tujuan terakhir. Respons dari tujuan sebelumnya tidak boleh menggantikan halaman aktif.                        |
| NAV-24 | Posisi scroll                            | Halaman baru dibuka pada bagian atas. Saat kembali ke daftar sebelumnya, pulihkan posisi scroll jika daftar dan konteksnya masih sesuai.                                                        |
| NAV-25 | Navigasi keyboard                        | Tautan, menu, dan tombol dapat dijangkau serta diaktifkan menggunakan keyboard. Setelah perpindahan halaman, fokus diarahkan ke area utama atau judul halaman secara konsisten.                 |
